# Cleenty Landing Page

Primeira fase da landing page one-page da Cleenty.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui / Radix primitives
- Lucide React

## Estado atual

Implementado:
- Header desktop/mobile
- Hero completo e responsivo
- CTA e navegação por anchors
- Base visual e tokens da marca
- `CONTENT.md` com a arquitetura e copy da one-page completa

Ainda não implementado visualmente:
- Serviços
- Como funciona
- Porquê Cleenty
- Área de serviço
- FAQ
- CTA final
- Footer

## Executar

```bash
npm install
npm run dev
```

## Observação

Os contactos, preços e limites de cobertura não foram inventados. Estão deixados como decisões comerciais pendentes no `CONTENT.md`.
